# Политика конфиденциальности — Timezone Guard

**Последнее обновление:** август 2026

Timezone Guard не собирает, не хранит и не передаёт никакие персональные данные.

## Какие данные хранятся

Единственное, что сохраняет расширение — это выбранный вами в попапе часовой пояс (например, `Europe/Helsinki`). Это значение сохраняется локально на вашем устройстве через API браузера `storage.local`.

- Эти данные никогда не покидают ваш браузер.
- Они не отправляются ни на какой сервер, третьим лицам или разработчику расширения.
- Используются только для того, чтобы определить, какое значение часового пояса сообщать сайтам.

## Что расширение делает на веб-страницах

Timezone Guard инжектит небольшой скрипт на каждую посещаемую вами страницу, чтобы подменить значения, связанные с часовым поясом, возвращаемые `Intl.DateTimeFormat` и методами `Date`. Этот скрипт:

- Выполняется полностью внутри вашего браузера.
- Не читает, не собирает и не передаёт никакой контент с посещаемых вами страниц.
- Не связывается ни с каким внешним сервером.

## Разрешения

- `storage` — для локального сохранения выбранного часового пояса.
- `<all_urls>` (host permission) — необходимо, чтобы подмена часового пояса применялась на любом сайте, который вы посещаете, до того, как выполнятся скрипты самой страницы.
