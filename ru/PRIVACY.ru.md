# Политика конфиденциальности — Timezone Guard

*[Read in English](../PRIVACY.md)*

**Последнее обновление:** август 2026

Timezone Guard не собирает, не хранит и не передаёт никакие персональные данные на внешние серверы.

## Какие данные хранятся локально

Расширение сохраняет на вашем устройстве следующие значения через API браузера `storage.local`:

1. **Часовой пояс** — выбранный вами в попапе часовой пояс (например, `Europe/Helsinki`).
2. **User-Agent** *(опционально)* — выбранный вами идентификатор браузера для подмены.
3. **Состояние расширения** — включено ли расширение (`enabled`) и активна ли подмена HTTP-заголовков (`spoofHeaders`).
4. **URL Service Worker'ов** — адреса зарегистрированных Service Worker'ов на посещаемых вами сайтах, нужные для повторного применения патчей после перезапуска браузера.

- Эти данные никогда не покидают ваш браузер.
- Они не отправляются ни на какой сервер, третьим лицам или разработчику расширения.
- Используются только для того, чтобы определить, какие значения сообщать сайтам.

## Временные данные в контексте страницы

Для передачи настроек между изолированным миром расширения и основным миром страницы расширение использует:

- **DOM-атрибуты** на элементе `<html>` — читаются синхронно при `document_start`; на сайтах из списка исключений (и при выключенном расширении) удаляются сразу после чтения, на спуфнутых сайтах сохраняются только на время жизни документа (нужны для восстановления из bfcache).
- **`sessionStorage` и `localStorage`** (ключ `__tzGuardConfig`) — резервный способ, позволяющий пережить перезагрузки страницы и восстановление из bfcache. На сайтах из списка исключений (и при выключенном расширении) записывается только нейтральная запись (`{enabled: false, whitelist}` — без значений таймзоны и UA), чтобы протухший кэш не мог «воскресить» спуф; текущий список исключений включается, чтобы правила всегда были актуальны.

Эти данные записываются в хранилище самой страницы и никогда не передаются за пределы браузера.

## Что расширение делает на веб-страницах

Timezone Guard инжектит небольшой скрипт на каждую посещаемую вами страницу, чтобы подменить значения часового пояса и (опционально) User-Agent, возвращаемые JavaScript API. Этот скрипт:

- Выполняется полностью внутри вашего браузера.
- Применяется в основном окне, iframe, Dedicated Workers, Shared Workers и Service Workers.
- Не читает, не собирает и не передаёт никакой контент с посещаемых вами страниц.
- Не связывается ни с каким внешним сервером.

Для Service Worker расширение временно модифицирует сетевой ответ скрипта Service Worker, внедряя код подмены. Это затрагивает только URL, зарегистрированные как Service Worker на посещаемых вами сайтах, и не изменяет никакой другой сетевой трафик.

## HTTP-заголовки

Когда в попапе включён переключатель **"Spoof HTTP Headers"`, расширение изменяет исходящие HTTP-заголовки запросов (`Accept-Language` и опционально `User-Agent`) в соответствии с выбранным часовым поясом и идентификатором браузера. Эта модификация происходит локально в вашем браузере до отправки запроса.

## Разрешения

- `storage` — для локального сохранения выбранных настроек и известных URL Service Worker'ов.
- `<all_urls>` (host permission) — необходимо, чтобы подмена применялась на любом сайте, который вы посещаете, до того как выполнятся скрипты самой страницы.
- `webRequest`, `webRequestBlocking`, `webRequestFilterResponse`, `webRequestFilterResponse.serviceWorkerScript` — необходимы исключительно для патчинга скриптов Service Worker через перехват сетевого ответа и для модификации HTTP-заголовков.
