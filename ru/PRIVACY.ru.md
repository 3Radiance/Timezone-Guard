# Политика конфиденциальности — Timezone Guard

*[Read in English](../PRIVACY.md)*

**Последнее обновление:** август 2026

Timezone Guard не собирает, не хранит и не передаёт никакие персональные данные.

## Какие данные хранятся

Расширение сохраняет локально на вашем устройстве два значения через API браузера `storage.local`:

1. **Часовой пояс** — выбранный вами в попапе часовой пояс (например, `Europe/Helsinki`).
2. **User-Agent** *(опционально)* — выбранный вами идентификатор браузера для подмены.

- Эти данные никогда не покидают ваш браузер.
- Они не отправляются ни на какой сервер, третьим лицам или разработчику расширения.
- Используются только для того, чтобы определить, какие значения сообщать сайтам.

## Что расширение делает на веб-страницах

Timezone Guard инжектит небольшой скрипт на каждую посещаемую вами страницу, чтобы подменить значения часового пояса и (опционально) User-Agent, возвращаемые JavaScript API. Этот скрипт:

- Выполняется полностью внутри вашего браузера.
- Применяется в основном окне, iframe, Dedicated Workers, Shared Workers и Service Workers.
- Не читает, не собирает и не передаёт никакой контент с посещаемых вами страниц.
- Не связывается ни с каким внешним сервером.

Для Service Worker расширение временно модифицирует сетевой ответ скрипта Service Worker, внедряя код подмены. Это затрагивает только URL, зарегистрированные как Service Worker на посещаемых вами сайтах, и не изменяет никакой другой сетевой трафик.

## Разрешения

- `storage` — для локального сохранения выбранного часового пояса и User-Agent.
- `<all_urls>` (host permission) — необходимо, чтобы подмена применялась на любом сайте, который вы посещаете, до того, как выполнятся скрипты самой страницы.
- `webRequest`, `webRequestBlocking`, `webRequestFilterResponse`, `webRequestFilterResponse.serviceWorkerScript` — необходимы исключительно для патчинга скриптов Service Worker через перехват сетевого ответа.
